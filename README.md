# LeetCode Algorithm Practice (Python)

这是一个个人 LeetCode 算法题解与编码练习仓库，包含 Python 算法题解、解题思路与经典解法归纳 —— 持续更新中。

## 📁 目录结构

```text
LeetCodeAlgorithm/
├── 数组与双指针/         # 数组操作、左右双指针、快慢指针、区间合并与划分
├── 字符串/               # 滑动窗口、回文串、字符串解析与匹配
├── 链表/                 # 链表反转、双指针、虚拟头节点、环与相交
├── 栈与哈希/             # 括号匹配、数独校验、哈希映射
├── 二分查找/             # 经典二分、左右边界二分、二维矩阵二分
├── 回溯与递归/           # 排列组合、括号生成、状态回退与剪枝
├── 动态规划与贪心/       # 线性 DP、网格 DP、序列匹配、贪心策略
├── 矩阵与模拟/           # 螺旋遍历、原地矩阵旋转、矩阵置零
└── 数学与位运算/         # 快速幂、大数运算、进制转换、数字反转
```
